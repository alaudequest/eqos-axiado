1. What mode 8 tests

Modes 4 and 5 test the transmitter: the MAC inserts tags into the frame. Mode 8 tests the receiver: the CPU writes the tag into the frame itself, the transmitter copies it unchanged (TDES2.VTIR = none, no context), the frame loops through loopback back to the receiver, and the receiver compares the tag with ETH_MACVTR. Everything happens on RX.

One case = one set of ETH_MACVTR values + one frame + one expectation. The fourteen cases change one filter bit at a time to show what that bit does. Every mode 8 case uses VTFE = 1 (drop non-matching frames), so the result is visible immediately as "did the frame come back or not".

2. The filter works in three steps

The easiest way to remember it is to picture the filter as a gatekeeper asking three questions, in order. If a question cannot be asked, it stops and does not block. Only when question 3 can be asked and the answer is "no match" is the frame dropped (with VTFE = 1).

The bits of step 3 (comparing the number)

BitValueComparisonCase
ETV [16]1compare the 12-bit VID: VL[11:0] == TCI[11:0], PCP/DEI ignoredB, D
ETV [16]0compare all 16 bits: VL[15:0] == TCI[15:0], PCP must match tooE
VL [15:0]0no comparison, every tag counts as a match (p.3124). With ETV = 1 only VL[11:0] = 0 is neededG
VTIM [17]1invert the result: match becomes no match and vice versa (blacklist)F1, F2
VTHM [25]1adds a hash door: the VID hashes to 0..15, and if that bit in ETH_MACVHTR is set it is a match. Runs in parallel with VLH1, H2

7. VF and RS2V: the MAC only reports VF = 1, never VF = 0

RDES2.VF[15] (p.3068) only means something when RDES3.RS2V[27] (p.3069) = 1. The board on 2026-11-16 (mode 9) showed that the MAC only writes RDES2 when the frame passes the filter: then RS2V = 1, VF = 1. In every other case, including a comparison that missed, the MAC leaves RDES2 = 0 and RS2V = 0. The code prints - when RS2V = 0; an expectation of "VF = 0" can never come true.

The descriptor cannot tell "missed" from "not applicable": both give RS2V = 0. Only behaviour tells them apart: VTFE = 1 drops a missed frame but not an out-of-scope frame (mode 8 C versus K1); EVLS = "strip on miss" strips a missed frame (mode 9 D1). The code uses VR_VF_NONE (expects RS2V = 0, prints -) for these cases, and VR_VF_ANY only when it is genuinely unknown.

Consequence for a real driver: to know whether a frame belongs to the filtered VLAN, reading VF = 1 is enough, but you cannot rely on the descriptor to count "foreign VLAN frames" when VTFE = 0. To count them, enable VTFE = 1 and read the MMC difference (the MMC counts before the filter, section 9), or use EVLS = "strip on miss" and look at the length.

8. VLAN hash table (ETH_MACVHTR, p.3124)

The exact-comparison door only accepts one VID. To accept several VLANs, enable VTHM and fill in the 16-bit table: the MAC hashes the VID into a number 0..15, and if that bit is set it is a match. The RM only says "the most significant four bits of the CRC of the VLAN tag". The software in vr_vid_hash_index() follows the Linux stmmac driver:

reflected CRC-32, poly 0xEDB88320, init 0xFFFFFFFF
feed the 12 VID bits in one at a time, starting from bit 0
index = bitrev32(~crc) >> 28          (top 4 bits, read reversed)

software:  VID 100 → 0,  VID 200 → 0,  VID 300 → 6,  VID 2000 → 8

Not checked on silicon yet. The first line of mode 8 prints these two indexes. If H1 is DROP: the formula is wrong. How to find the real bit: loop 16 times, each time MACVHTR = 1 << i, send VID 200; the i that PASSes is the real index. Then compare with the formula to fix it.

Mode 9 lessons

  • Stripping loses no information: the TCI always remains in RDES0 (EVLRXS / EIVLRXS), the length RDES3.PL is the length after stripping, and LT is the number of tags in the incoming frame.
  • "Strip on miss" (D1) is the only way to see that the filter ran when VTFE = 0, because the descriptor does not report misses.
  • The tag type check (ERSVLM) comes before everything else: E, F with an S-tag and ERSVLM = 0 give RS2V = 0 even with VL = 0. To get VF = 1 with QinQ, use ERSVLM = 1 (filter the S tag) or ERIVLT = 1 (look at the inner C tag).
  • Cases worth adding: EVLS = if pass with ERSVLM = 1 and VL 2000 on vr_fq (strip the S-tag because it matches, VF = 1); EIVLS = if pass with ERIVLT = 1, VL 100 (strip the inner tag, keep the outer: outgoing frame 88 A8 07 D0 88 B5).
