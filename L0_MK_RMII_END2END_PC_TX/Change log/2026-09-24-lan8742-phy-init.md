# Restore LAN8742 PHY initialization - 2026-09-24

## Changes

- `CM7/Core/Src/main.c` now includes the original `lan8742.h` and uses the
  unchanged `CM7/Core/Src/lan8742.c` implementation.
- Restored the LAN8742 object, bus IO context, and ETH_PHY_INTERFACE callbacks.
  Register read/write callbacks call eqos_mdio_read/write; GetTick uses HAL_GetTick.
  The IO Init callback is a no-op because eqos_init has already prepared GPIO,
  clocks, MAC reset, and the MDIO divider before calling the PHY hook.
- Added an optional phy_init callback to eqos_cfg in `CM7/baremetal/eqos.h` and
  invoked it at the existing PHY bring-up step in `eqos.c`. This avoids running
  both the generic PHY initializer and LAN8742_Init. NULL retains the generic path.
- ETH_PHY_Init in main.c registers bus IO, calls LAN8742_Init and
  LAN8742_StartAutoNego, then waits for LAN8742_GetLinkState to report one of the
  four valid 10/100 Mbps half/full duplex states. The PHY address and negotiated
  mode are passed to eqos, which configures MAC/MTL/DMA as before.
- Link-down and auto-negotiation-not-done are explicitly treated as waiting states.
  PHY errors are printed with their original LAN8742 status and returned as
  EQOS_EIO; link wait expiration returns EQOS_ENOLINK.

## Startup and debugging

Break at ETH_PHY_Init, LAN8742_Init, ETH_PHY_INTERFACE_ReadReg/WriteReg, and
LAN8742_GetLinkState. Watch LAN8742.DevAddr and eth.speed/duplex_full/link_up.
The unchanged LAN8742_Init includes its own reset timeout and approximately
2-second settling delay. The application then allows up to 5 seconds for link.
Connect the cable before reset. HAL tick interrupts must remain enabled during
PHY initialization. IO callbacks are intentionally bound to the single eth device.

TX/RX, pin assignments, D-cache policy, and button behavior are unchanged.
Automatic cable reconnection remains outside this change; eqos_poll_link is not
called by the application and retains its generic Clause 22 implementation.
The 2026-09-23 log is historical: its generic PHY startup description and ELF
addresses/size are superseded by this rebuild.
